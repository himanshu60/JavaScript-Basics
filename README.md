## How these notes are written

Every topic file follows the same structure:

1. **Definition** — what the thing is, in one clear sentence
2. **In simple words** — an everyday analogy
3. **Types / parts** — each sub-item defined separately before it is used
4. **Examples** — runnable code with comments explaining each line
5. **Comparison table** — where two things are commonly confused
6. **Key points** — a summary to revise from
